## In-game usage

- Toggle edit mode with `/mia lootcrates edit`, loot crates can only be placed and broken while in it
- Take a crate for any loot table from `/mia lootcrates menu`, right click an entry to preview its loot
- Right clicking a crate in edit mode previews its loot, or opens the item editor for custom loot crates
- `/mia lootcrates inspect` shows the table, restock time and loot state of the crate you are looking at
- `/mia lootcrates reset all` or `/mia lootcrates reset player <name>` lets a crate be looted again
- `/mia lootcrates migrate check|run <file>` replaces old chest crates listed in a file under `plugins/MineInAbyss` with furniture crates
